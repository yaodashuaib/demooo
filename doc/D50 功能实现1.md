# 余额功能

D50下位机可以显示agent的一个余额用量，分为几种显示模式：DOUBLE\_BAR、SINGLE\_BAR、TEXT、VALUE

如下是发送给下位机显示的字符串json：

```plaintext
{
  "Agents": [
    {
      "Name": "Agent 1",
      "AgentIndex": 0,
      "Type": "DOUBLE_BAR",
      "Bars": [
        {"LeftLabel": "5小时剩余", "RightLabel": "80%", "Value": 80},
        {"LeftLabel": "周剩余", "RightLabel": "42% · 周五重置", "Value": 42}
      ]
    },
    {
      "Name": "Agent 2",
      "AgentIndex": 1,
      "Type": "SINGLE_BAR",
      "Bars": [
        {"LeftLabel": "可用余额", "RightLabel": "$18.50", "Value": 62}
      ]
    },
    {
      "Name": "Agent 3",
      "AgentIndex": 2,
      "Type": "TEXT",
      "Text": "当前套餐：Pro\n本月已使用：128次\n续费日期：2026-11-01"
    },
    {
      "Name": "Agent 5",
      "AgentIndex": 4,
      "Type": "VALUE",
      "Label": "Balance",
      "ValueText": "2400"
    }
  ]
}
```

支持的agent包括：claude code、codex、kimi、workbuddy，这些分有客户端和cli的形式。

余额获取可以参考[https://github.com/steipete/CodexBar](https://github.com/steipete/CodexBar) 这个项目以及源码

C:\Users\aa\AppData\Roaming\Ulanzi\linked-apps.json，这里存放的是已配置的列表，在连接上D50设备后，获取到列表agent各余额后，全量下发给D50；

考虑余额是会更新的，需要定时轮询获取然后更新；客户端新增一项agent时，也会同步余额到下位机；

注意：图片发送和余额发送，会存在指令竞争，需要一个队列，一个指令ACK后，排队中的再执行

耗时的操作都是需要异步处理和消耗的
